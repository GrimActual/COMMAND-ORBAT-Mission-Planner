# Release scope and evidence boundaries

COMMAND v1.0.0 is the stable offline planner product edition, following the owner’s explicit approval on 20 October 2026 to publish planning as stable and retain all connected controls as experimental. The prior whole-product stable gate is not claimed passed: two-client multiplayer and human pilot takeover remain pending.

Stable: mission planning, save/load, supported planning-data import/export, catalog selection, drawings/briefing, Undo/Redo, settings, recovery, Sarge, unified workspace and portable mission packages. Experimental: all live-game integrations, optional read-only terrain preview and migration review tools. Disabled/planned capabilities remain on the preserved full roadmap.

User-observed live spawn/flight results supplement existing isolated native evidence. Fresh package checks validate only the packaged desktop flows and recorded boundaries; no normal game client is launched. No pending human test is marked passed. General existing-vehicle registration and the historical boarding timeout remain unresolved.

The package manifest records the immutable source revision. SOURCE-MANIFEST.json maps components to that revision; FILE-MANIFEST.json and SHA256SUMS.txt cover frozen contents. Source excludes private diagnostics, private samples, credentials, protected game assets and unlicensed imagery. Historical documentation is retained as history in corresponding source.
