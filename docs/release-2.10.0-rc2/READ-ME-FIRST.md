# COMMAND 2.10 — Mission Planning & Control

Consolidated test candidate: desktop **2.10.0-rc.2**, matching bridge project **0.13.0**, included HTTPS relay. This package is awaiting acceptance, not an approved stable release.

1. Export a backup of your current plan. Extract the entire package into a new folder; preserve your previous installation. Open COMMAND-Windows/COMMAND Planner.exe. No connection starts automatically.
2. Start with [the desktop guide](Guides/00-START-HERE.md). Vanilla-Assets contains the matching catalog/resource-index pairs. User-supplied permitted map imagery/elevation is optional; clean offline coordinate-grid planning works without it.
3. Bridge-0.13.0/addon.gproj is the matching unpublished publication project. Install/publish and verify the actual Workshop version before live acceptance. Enable only one copy of this addon identity. A desktop update does not update the game mod.
4. Use [Watchtower](Test-Mission-Watchtower/00-START-HERE.md) for the original ground-control mission and [the Huey pack](Test-Mission-Huey/00-START-HERE.md) for the separate experimental occupied deployment/flight check. Importing a plan installs no game orders.
5. Complete [the remaining acceptance checks](ACCEPTANCE-CHECKLIST.md). Review [upgrade/recovery](UPGRADE-AND-RECOVERY.md) and [scope](RELEASE-SCOPE.md). Stable publication requires recorded acceptance against the final package checksum.

Contents: complete desktop app, matching original bridge source, standalone relay, vanilla metadata, current guides/config examples, two test packs, neutral composition examples, licenses/notices, corresponding source and checksums. Raw private diagnostics, credentials, private samples, proprietary game assets and unlicensed map images are excluded.
