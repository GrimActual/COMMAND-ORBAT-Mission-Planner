# Searchable asset browser

In Units, choose the military unit type and click Browse assets. Infantry shows troops; Armor shows armoured vehicles. Mechanized, Motorized, Rotary Wing, Fixed Wing and Logistics have matching filters. Change Asset type to All asset types to browse more broadly. These are metadata hints, not native spawn guarantees.

Search name, prefab path or GUID. Filter by prefab faction independently from the planned unit faction. Use Previous and Next for paged results. Uncheck Include base templates and damaged variants to hide recognised helper/template folders.

Choosing a result edits only the current form. Click Apply changes for an existing unit, or Place new unit for a new marker. The exact resource reference remains unchanged. Browsing, filtering and language changes do not save mission edits. Existing assigned snapshots remain available after catalog replacement.

Settings → General → Browse assets opens the same chooser. Sarge → Import assets and mods explains catalog imports and matching resource indexes. A blank deployment name now produces a specific instruction to enter a name and Apply changes.
