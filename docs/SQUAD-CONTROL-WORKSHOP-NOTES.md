COMMAND ORBAT Bridge 0.9.0 — existing AI squad control pilot

Adds host-approved recruitment of selected existing on-foot AI squads, release without deleting them, and Follow of an explicitly selected same-faction player for 5–300 seconds. Uses the native Follow entity waypoint. Selection, faction, membership and target checks remain server-side. Follow ends on expiry, target loss or respawn; a fresh order is required afterward.

Requires matching Companion 2.9.1-dev.followon.5. New commands negotiate their own capabilities. Move, timed Hold, Defend, routes, named tracking and faction symbols remain supported. The tracking limit remains 60. No vehicle, formation, stance, fire-control or building-entry commands are added.

Native compilation, synthetic lifecycle and offline desktop checks passed. Real-player following, terrain navigation/arrival and broader multiplayer acceptance remain experimental.
