# Scoped test outputs

Some original COMMAND checks write generated receipts in this directory. Keep this directory when extracting the corresponding source. Generated outputs are not automatically release evidence: record the tested revision, artifact and actual scope. Raw private native logs, profiles, credentials, installation inventories and third-party source material belong outside the repository and public packages.

The corresponding-source archive excludes generated evidence outputs while preserving this note and all original tests. Public candidate acceptance summaries are supplied separately and distinguish offline contracts, isolated native execution and required human multiplayer checks.
