# Named live markers and faction organization — development candidate

The catalog browser uses default faction/origin hints: explicit prefab faction folders first, explicit FIA/civilian/US/USSR variants second, then bounded known vehicle-family mappings. Unknown models stay unspecified. All factions remain available. No imported asset, selected unit side, prefab identity or in-game faction is rewritten by these filters.

Live metadata uses the entity’s actual server-side faction and PlayerManager name, not catalog origin. The first protocol-3 packet remains coordinate-only. A new relay advertises identityMetadata=1 in its accepted batch response; only then does the new sender include bounded label/faction/kind fields. Older relays never receive the extension. Identity-only changes bypass the movement threshold; ordinary coordinate deltas, shared cap 60, heartbeat expiry and pairing ownership remain unchanged.

The desktop uses faction-shaped symbols and permanent name labels. Player, AI and vehicle glyphs differ. Unknown factions and older anonymous feeds remain unidentified; no allegiance is guessed from a vehicle model or tracking alias. The displayed name is server-reported, not an authenticated account credential. Labels use text nodes, never imported HTML. Live information remains outside saved missions and Undo. Exports containing personal player names should be kept private.

Testing: use the matching desktop and updated bridge candidate, start a fresh pairing, explicitly select humans/AI/factions in the in-game roster, and resume. Names should appear after the initial capability exchange, normally within two update intervals. Existing Workshop 0.6.0 cannot provide names. Check a player name, a different faction, stationary identity updates, stale disappearance, reconnect and 60-marker performance. Native compilation is separate from real multiplayer acceptance.

Validation completed: 25 focused desktop/contract tests and 4 standalone-relay tests passed. The native candidate compiled with the standalone diagnostic server; an actual isolated loopback test observed anonymous baseline, negotiated identity metadata and a stationary synthetic name change. No real-player or multiplayer acceptance is claimed. Workbench itself crashed during startup before script validation. A matched 60-marker desktop sample measured 57.02 FPS with p95 16.8 ms and no frames above 100 ms over three seconds; the prior circle-marker sample measured 60.36 FPS. This is a short local sample, not a sustained 60-player performance guarantee.

The test executable remains work/next100/COMMAND-Initialization-Candidate/COMMAND Planner.exe, now version 2.9.1-dev.followon.3. The clean Workshop update is publish/COMMAND-ORBAT-Bridge-0.7.0/addon.gproj. Existing 0.6.0 remains intact. Permanent map labels show the name; clicking an icon shows faction, type and grid. Live vehicle identity applies to explicitly tracked vehicle entities; this update does not add automatic whole-world vehicle discovery.
