# Upgrade, compatibility and recovery

Before switching, export Project JSON and keep that file unchanged. Close the old app, preserve its whole installation and extract this package to a new folder. Do not merge old resources with new ones. COMMAND retains the established settings/storage identity; it does not automatically reset preferences, catalogs or user missions. Run one COMMAND copy at a time.

Ordinary plans remain format 4. Optional reviewed Workbench pose provenance uses format 5; older readers may reject it. Never overwrite your only original backup. Native bridge/relay state and credentials are separate from mission save/Undo.

Update the existing Workshop item with Bridge-0.12.1 using its preserved project GUID; confirm the published version actually downloaded. Restart the hosted scenario and create a fresh pairing. Do not activate duplicate copies of the same addon. Companion's version alone cannot update the game. New approvals require the game host or explicitly configured server administrator.

If connection fails, copy the displayed error, check the actual mod/version and HTTPS endpoint, and use Disconnect dashboard or End session deliberately. Quick connection owns its helper; remote disconnection leaves server-managed infrastructure running. Never post pairing/dashboard/tunnel keys publicly. Public tunnel DNS can need a warm-up; a failed readiness check issues no pairing code.

If planning changes are wrong, use Undo, recovery copies or reimport your original Project JSON. If needed, close this app and return to the preserved previous installation with its original-format backup. Newer-format plans may require the newer reader. Server snapshots are limited COMMAND-managed packages, not complete game saves; review before restore and back up the server's profile/COMMAND-Scenarios folder through your normal administrator process. Old wrong headings cannot be reconstructed automatically.

Workshop upload 500 errors do not prove script failure. Preserve the existing item identity, retain the error UID/log privately and retry or contact Bohemia support if it persists. Do not create duplicate items or regenerate GUIDs as a workaround.
