# Operation Watchtower - Start

Aktuellen Plan sichern. Assets: **02-MISSION-ASSET-CATALOG.json** importieren. Plan files -> Import plan: **01-MISSION-PLAN.json**. Game controls -> Deploy: Ressourcenindex **03-MISSION-RESOURCE-INDEX.json** laden. Die 12 freundlichen Marker wählen, Referenzen und Positionen prüfen, senden und einmal im Spiel genehmigen. Der Import allein erzeugt keine Einheiten.

Besatzungen und Passagiere erscheinen neben den Fahrzeugen: Einsteigen wird separat geprüft, gesendet und genehmigt. Zwei Bodenfahrzeuge und ein UH-1H sind vorgesehen. COMMAND bietet keine Flugbefehle; Spieler/Game Master muss fliegen. Bekannte Einstiegszeitüberschreitungen bleiben ungeklärt.

04 enthält nur zwei optionale Gegnerteams; sie können sofort angreifen. 05 ist ausschließlich eine **Offline-Probe**, ohne Spielbefehle. Vollständiges Briefing unter Brief; Ablauf und Befehle in 06-ORDERS-AND-RADIO.md. Bei Rückkehr zu Datei 01 die freundliche Gruppe nicht erneut erzeugen.
